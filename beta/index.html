Origional Interaction:

Favoriing an Item

1. Favorite Toggle

LOCATION

  • The Favorite Toggle will be found near the product image.

TRIGGERS

  • Hover ON
  • Hover OFF
  • Click ON
  • Click OFF

RULES


Hover ON

  • Cursor changes from an arrow to a pointer hand.
  • Heart drops a faint light blue shadow that borders its silhouette on all sides.
  • Heart slighly grows in size from 1.0 to 1.1

Hover OFF

  • Cursor changes from pointer hand back to the default arrow.
  • Faint blue shadow is removed from the border outline of the heart.
  • Heart slightly shrinks from 1.1 and returns to the default size at 1.0

Click ON

  • Heart changes from a the white/empty state to a solid blue filled state, with the blue outline.
  • Product changes from unfavorited to favorited in the database.

Click OFF

  • Heart undergoes a heart split animation (lasting 1 second), cracking in half. The pieces animate the outward separation smoothly.
  • Sparks pop out of the heart, 3 short blue lines on the top, and 2 short lines on the lower left and right side, adding emphasis to the action of unfavoriting an item. This occurs at the same time as the heartbreak animation, last 1 second as well.
  • Heart returns to the default state with solid white/empty fill, and only a blue border.
  • Product changes from favorited to unfavorited in the database.

FEEDBACK

  • Heart returns to the default state with solid white/empty fill, and only a blue border.

2. Favorites Tab Button

LOCATION

  • The Favorites Tab Button will be found in the top navigation bar.

TRIGGERS

  • Hover ON
  • Hover OFF
  • Mouse DOWN
  • Mouse UP

RULES


Hover ON

  • Cursor changes from an arrow to a pointer hand.
  • Heart icon slighly shrinks in size from 1.0 to .8
  • Heart icon slightly shortens in height from 1.0 to .8
  • 3 short streaks/lines pop out at the top of the favorite icon

Hover OFF

  • Cursor changes from pointer hand back to the default arrow.
  • Heart icon slighly increases in size from .8 to 1.0
  • Heart icon slightly increases in height from .8 to 1.0
  • The 3 short streaks/lines that popped out at the top of the favorite icon dissapear

Mouse DOWN

  • Heart icon increases in size from 1.0 to 1.2. It only stays at this size while the cursor is actively pressing down on the favorites button.
  • The 3 short streaks/lines that popped out at the top of the favorite icon increase in size, proportionally to the heart.

Mouse UP

  • The heart icon then decreases from 1.2 to 1.0.
  • The 3 short streaks/lines that popped out at the top of the favorite icon dissapear entirely
  • Page opens to the user's favorited items
