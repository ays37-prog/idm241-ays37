Favoriing an Item

Favorite Toggle

LOCATION

  • The Favorite Toggle is found upon opening the link to the Marshlls product. The heart shaped icon is in the center of the page, with a blue outline and empty fill.

TRIGGERS

  • Hover ON
  • Hover OFF
  • Click ON
  • Click OFF

RULES


Hover ON

  • Cursor changes from an arrow to a pointer hand.
  • Heart slightly increases in size from 1.0 to 1.08.

Hover OFF

  • Cursor changes from pointer hand back to the default arrow.
  • Heart returns to its original size from 1.08 to 1.0.

Click ON

  • Heart changes from a the white/empty state to a solid blue filled state, with a blue outline.
  • Heart performs one bounce animation (shrinking in size to 0.8, then growing to 1.22, then shrinking to .95, and finally growing back to 1.0).
  • Product changes from unfavorited to favorited in the database.

Click OFF

  • Heart changes from a blue filled state to a solid white/empty state, with only a blue outline.
  • Heart performs one bounce animation (shrinking in size to 0.8, then growing to 1.22, then shrinking to .95, and finally growing back to 1.0).
  • Product changes from favorited to unfavorited in the database.

FEEDBACK


Hover ON

  • Cursor visually changes from an arrow to a pointer hand.
  • Heart slightly increases in size from 1.0 to 1.08.

Hover OFF

  • Cursor visually changes from a pointer hand back to an arrow.
  • Heart returns to its original size from 1.08 to 1.0.

Click ON

  • Heart changes from a the white/empty state to a solid blue filled state, with a blue outline.
  • Heart performs one bounce animation (growing in size to 1.22, then shrinking to .95, then growing to 1.08, and finally shrinking back to 1.0).

Click OFF

  • Heart changes from a blue filled state to a solid white/empty state, with only a blue outline.
  • Heart performs one bounce animation (growing in size to 1.22, then shrinking to .95, then growing to 1.08, and finally shrinking back to 1.0).

Favorites Counter

LOCATION

  • The subsequent favorite counter can be found in the navigation bar, as a smaller heart icon, with a blue outline and empty fill.

TRIGGERS

  • Hover ON
  • Hover OFF
  • Click ON
  • Favorite Toggle Click ON
  • Favorite Toggle Click OFF

RULES


Hover ON

  • Cursor changes from an arrow to a pointer hand.
  • Heart changes from a the white/empty state to a solid blue filled state, with a blue outline.

Hover OFF

  • Cursor changes from pointer hand back to the default arrow.
  • Heart changes from a blue filled state to a solid white/empty state, with only a blue outline.

Click ON

  • Page opens to the "My Favorites" tab on the website.

Favorite Toggle Click ON

  • Heart changes from a the white/empty state to a solid blue filled state, with a blue outline.
  • Heart and "Favorites" label performs one bounce animation (growing in size to 1.22, then shrinking to .95, then growing to 1.08, and finally shrinking back to 1.0).
  • Total favorited items counter increases by 1.
  • Product changes from unfavorited to favorited in the database.

Favorite Toggle Click OFF

  • Heart changes from a blue filled state to a solid white/empty state, with only a blue outline.
  • Heart and "Favorites" label performs one bounce animation (growing in size to 1.22, then shrinking to .95, then growing to 1.08, and finally shrinking back to 1.0).
  • Total favorited items counter decreases by 1.
  • Product changes from favorited to unfavorited in the database.

FEEDBACK


Hover ON

  • Cursor changes from an arrow to a pointer hand.
  • Heart changes from a the white/empty state to a solid blue filled state, with a blue outline.

Hover OFF

  • Cursor changes from pointer hand back to the default arrow.
  • Heart changes from a blue filled state to a solid white/empty state, with only a blue outline.

Click ON

  • Page opens to the "My Favorites" tab on the website.

Favorite Toggle Click ON

  • Heart changes from a the white/empty state to a solid blue filled state, with a blue outline.
  • Heart and "Favorites" label performs one bounce animation (growing in size to 1.22, then shrinking to .95, then growing to 1.08, and finally shrinking back to 1.0).
  • Total favorited items counter increases by 1.

Favorite Toggle Click OFF

  • Heart changes from a blue filled state to a solid white/empty state, with only a blue outline.
  • Heart and "Favorites" label performs one bounce animation (growing in size to 1.22, then shrinking to .95, then growing to 1.08, and finally shrinking back to 1.0).
  • Total favorited items counter decreases by 1.

Confirmation Pop-Up Notification

LOCATION

  • The confirmation pop-up notification can be found only after toggling on the favorite icon, and the pop up will appear underneath the favorites counter.

TRIGGERS

  • Favorite Toggle Click ON
  • "My Favorites" Button Hover ON
  • "My Favorites" Button Hover OFF
  • "My Favorites" Button Click ON

RULES


Favorite Toggle Click ON

  • Confirmation Notification appears on screen, under the favorites counter, displaying "Saved!" with a "My Favorites" button encapsulated in a white box.
  • This pop up notification only stays on the screen for 3 seconds.

"My Favorites" Button Hover ON

  • Cursor changes from an arrow to a pointer hand.
  • "My Favorites" button changes from the default blue fill with white text, to a blue outline only, a white/empty background, and blue text.

"My Favorites" Button Hover OFF

  • Cursor changes from the pointer hand back to an arrow.
  • "My Favorites" button changes from the blue outline, white/empty background, and blue text, back to the default state of a filled blue background with white text.

"My Favorites" Button Click ON

  • Page opens to the "My Favorites" tab on the website.

FEEDBACK


Favorite Toggle Click ON

  • Confirmation Notification appears on screen, under the favorites counter, displaying "Saved!" with a "My Favorites" button encapsulated in a white box.

"My Favorites" Button Hover ON

  • Cursor changes from an arrow to a pointer hand.
  • "My Favorites" button changes from the default blue fill with white text, to a blue outline only, a white/empty background, and blue text.

"My Favorites" Button Hover OFF

  • Cursor changes from the pointer hand back to an arrow.
  • "My Favorites" button changes from the blue outline, white/empty background, and blue text, back to the default state of a filled blue background with white text.

"My Favorites" Button Click ON

  • Page opens to the "My Favorites" tab on the website.
