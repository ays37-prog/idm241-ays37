1. Favorite Toggle

TRIGGERS

  • Hover ON
  • Hover OFF
  • Click ON
  • Click OFF

RULES


Hover ON

  • Cursor changes from an arrow to a pointer hand.
  • Heart drops a faint light blue shadow that borders its blue border on all sides.
  • Heart slighly grows in size from 1.0 to 1.08

Hover OFF

  • Cursor changes from pointer hand back to the default arrow.
  • Faint blue shadow is removed around the blue border outline of the heart.
  • Heart slightly shrinks from 1.08 and returns to the default size at 1.0

Click ON

  • Heart changes from a the white/empty state to a solid blue filled state, with the blue outline.
  • Product changes from unfavorited to favorited in the database.

Click OFF

  • Heart undergoes a heartbreak animation (lasting 1 second), cracking in half evenly, and both pieces drifting apart.
  • Heart returns to the unbroken default state with solid white/empty fill, and only a blue border.
  • Product changes from favorited to unfavorited in the database.

FEEDBACK

2. Menu Favorites Button

TRIGGERS

  • Hover ON
  • Hover OFF
  • Mouse DOWN
  • Mouse UP
  • Favorite Toggle Clicked

RULES


Hover ON

  • Cursor changes from an arrow to a pointer hand.
  • Heart icon slighly decreases in size from 1.0 to 0.8
  • 3 short streaks pop out at the top of the favorite's tab button

Hover OFF

  • Cursor changes from pointer hand back to the default arrow.
  • Heart icon slighly increases in size from 0.8 to 1.0
  • 3 short streaks at the top of the favorite tab button dissapear

Mouse DOWN

  • Heart icon increases in size from 1.0 to 1.2. It only stays at this size while the cursor is actively pressing down on the favorites button.
  • The 3 short streaks/lines that popped out at the top of the favorite icon increase in size from 1.0 to 1.2. It only stays at this size while the cursor is actively pressing down on the favorite's button.

Mouse UP

  • The heart icon then decreases in size from 1.2 to 1.0.
  • The 3 short streaks/lines that popped out at the top of the favorite icon shrink in size from 1.2 to 1.0, and dissapear entirely
  • Page opens to "My Favorites""

Favorite Toggle Clicked

  • The navigation heart icon undergoes a pop animation, increasing in size from 1,0 to 1.3, then shrinking to 0.9, then returning to 1.0
  • The 3 short streaks/lines at above the favorite tab heart undergo a pop animation, increasing in size from 0.5 to 1.25, then decreasing to 1.0
  • Page opens to "My Favorites""
