Origional Favoriting Interaction:

Favoriting an Item

1. Favorite Toggle

LOCATION

  • The Favorite Product Toggle will be found in the top right corner of a product card.

TRIGGERS

  • Hover ON
  • Hover OFF
  • Click ON
  • Click OFF

RULES


Hover ON

  • Cursor changes from an arrow to a pointer hand.
  • Circular Heart button drops a faint light blue shadow.

Hover OFF

  • Cursor changes from pointer hand back to the default arrow.
  • Faint blue shadow is removed from around the circular heart button.

Click ON

  • Heart icon changes from a the white/empty state to a solid blue filled state, with the blue outline.
  • Product undergoes one bounce animation, growing, then shrinking, then growing back to its origional size.
  • Product changes from unfavorited to favorited in the database.

Click OFF

  • Heart icon undergoes a heart split animation (lasting 1 second), cracking in half with a white gap separating the left and right heart pieces. The pieces animate outwards smoothly.
  • Heart icon returns to one singular unified piece with solid white/empty fill.
  • Product changes from favorited to unfavorited in the database.

FEEDBACK


Hover ON

  • Cursor changes from an arrow to a pointer hand.
  • Circular Heart button drops a faint light blue shadow.

Hover OFF

  • Cursor changes from pointer hand back to the default arrow.
  • Faint blue shadow is removed from around the circular heart button.

Click ON

  • Heart icon changes from a the white/empty state to a solid blue filled state, with the blue outline.
  • Product undergoes one bounce animation, growing, then shrinking, then growing back to its origional size.

Click OFF

  • Heart icon undergoes a heart split animation (lasting 1 second), cracking in half with a white gap separating the left and right heart pieces. The pieces animate outwards smoothly.
  • Heart icon returns to one singular unified piece with solid white/empty fill.

LOOP & &MODES

  • N/A

2. Favorites Page Navigation Button

LOCATION

  • The Favorites Page Navigation Button is found in the top navigation bar.

TRIGGERS

  • Hover ON
  • Hover OFF
  • Click ON
  • Item Added / Removed from Favorites

RULES


Hover ON

  • Cursor changes from an arrow to a pointer hand.
  • Heart icon slighly increases in size.

Hover OFF

  • Cursor changes from the pointer hand back to the default arrow.
  • Heart icon slighly dacreases in size.

Click ON

  • Heart icon undergoes 1 bounce animation, growing in size, then shrinking, then growing back to its origional size.
  • Page opens to the "My Favorites" tab and displays every favorited item below in their own product card.

Item Added / Removed from Favorites

  • Heart icon undergoes 1 bounce animation, growing in size, then shrinking, then growing back to its origional size.
  • Favorited items counter increases by 1 integer if an item is favorited.
  • Favorited items counter decreases by 1 integer if an item is unfavorited.

FEEDBACK


Hover ON

  • Cursor changes from an arrow to a pointer hand.
  • Heart icon slighly increases in size.

Hover OFF

  • Cursor changes from the pointer hand back to the default arrow.
  • Heart icon slighly dacreases in size.

Click ON

  • Heart icon undergoes 1 bounce animation, growing in size, then shrinking, then growing back to its origional size.
  • Page opens to the "My Favorites" tab and displays every favorited item below in their own product card.

Item Added / Removed from Favorites

  • Heart icon undergoes 1 bounce animation, growing in size, then shrinking, then growing back to its origional size.
  • Favorited items counter increases by 1 integer if an item is favorited.
  • Favorited items counter decreases by 1 integer if an item is unfavorited.

3. Add to Cart Button

LOCATION

  • The Add to Cart Button is found at the bottom of each product card.

TRIGGERS

  • Hover ON
  • Hover OFF
  • Click ON
  • Click OFF

RULES


Hover ON

  • Cursor changes from an arrow to a pointer hand.
  • A rightwards pointing arrow is added before "Add to Bag" label. All text is white.
  • Entire text label is swiped rightwards slightly from its default centered position.
  • Rounded light blue underlay swipes in from the left, moving rightwards with the label/text content.

Hover OFF

  • Cursor changes from pointer hand back to the default arrow.
  • The rightwards pointing arrow is removed before "Add to Bag" label.
  • Entire label is swiped back to its normal centered position.
  • Rounded light blue underlay swipes back to the left with the label/text content, dissapearing, having only the solid dark blue background fill.

Click ON

  • Entire "Add to Bag" label swipes rightwards, dissapearing from screen.
  • The new "Remove from Bag" label swipes in from the left to the center of the button. This text is dark blue.
  • Rounded light blue underlay completely swipes rightwards, filling in the entire button.
  • Product changes from "Not in Bag" to "Added to Bag" in database.

Click OFF

  • Entire "Remove from Bag" label swipes rightwards, dissapearing from screen.
  • Rounded light blue overlay swipes rightwards, dissapearing from screen, revealing the default solid dark blue background.
  • White "Add to Bag" text swipes in rightwards, stopping at the center of the button.
  • Product changes from "Added to Bag" to "Not in Bag" in database.

FEEDBACK


Hover ON

  • Cursor changes from an arrow to a pointer hand.
  • A rightwards pointing arrow is added before "Add to Bag" label. All text is white.
  • Entire text label is swiped rightwards slightly from its default centered position.
  • Rounded light blue underlay swipes in from the left, moving rightwards with the label/text content.

Hover OFF

  • Cursor changes from pointer hand back to the default arrow.
  • The rightwards pointing arrow is removed before "Add to Bag" label.
  • Entire label is swiped back to its normal centered position.
  • Rounded light blue underlay swipes back to the left with the label/text content, dissapearing, having only the solid dark blue background fill.

Click ON

  • Entire "Add to Bag" label swipes rightwards, dissapearing from screen.
  • The new "Remove from Bag" label swipes in from the left to the center of the button. This text is dark blue.
  • Rounded light blue underlay completely swipes rightwards, filling in the entire button.

Click OFF

  • Entire "Remove from Bag" label swipes rightwards, dissapearing from screen.
  • Rounded light blue overlay swipes rightwards, dissapearing from screen, revealing the default solid dark blue background.
  • White "Add to Bag" text swipes in rightwards, stopping at the center of the button.
